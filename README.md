# Meu Portfólio Profissional

Este é o projeto final desenvolvido durante o módulo de **HTML5 e CSS3** da plataforma **Estudonauta / Curso em Vídeo**, sob orientação do professor Gustavo Guanabara. O objetivo deste projeto é consolidar o aprendizado em marcação semântica, estilização moderna, responsividade e organização de projetos web.

## 🚀 Tecnologias Utilizadas

* **HTML5** (Estruturação semântica)
* **CSS3** (Layouts com Grid/Flexbox, Variáveis nativas e Responsividade com Media Queries)
* **Font Awesome** (Ícones da interface)
* **JavaScript** (Funcionalidades de tema e scroll - *veja a nota de créditos abaixo*)

## 🎯 Funcionalidades do Projeto

* **Layout Responsivo:** Adaptado perfeitamente para dispositivos móveis, tablets e desktops usando Media Queries.
* **Alternador de Tema (Dark/Light Mode):** Interface dinâmica que respeita a escolha do usuário e a salva no navegador através do `localStorage`.
* **Scroll Suave:** Navegação fluida entre as seções da página através do menu fixo (Sticky Header).
* **Efeito de Transição (Hover):** Feedbacks visuais modernos nos cards de projetos e formação acadêmica.

## 📝 Nota sobre o JavaScript

Como estou atualmente em transição de carreira e focando no domínio completo do **HTML5** e **CSS3**, os scripts de interatividade presentes neste projeto (`scripts/script.js`) — que controlam o comportamento do tema escuro e o scroll suave — **foram disponibilizados pelo professor Gustavo Guanabara**. 

Ainda não iniciei meus estudos formais em JavaScript, mas o código foi mantido para garantir a experiência completa da interface e serve como introdução aos meus próximos passos nos estudos de Front-end.
